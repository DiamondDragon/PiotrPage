# Сайт-визитка «Wykończenia Wnętrz Piotr Janicki»

Шаблон для GitHub Pages. Каждая папка внутри `galerie/` — это отдельная галерея.
Все галереи показываются на одной странице в разделе «Realizacje». Клик по обложке
открывает просмотр всех фото этой галереи.

## Как добавить галерею

1. Скопируйте папку-образец `_wzor-galerii/` в `galerie/` и переименуйте её,
   например в `galerie/kuchnia-baluty/`. Имя папки пишите латиницей, маленькими
   буквами и через дефис, без пробелов и польских букв: оно станет частью ссылки.
2. Положите в эту папку фотографии (`.jpg`, `.jpeg`, `.png`, `.webp`).
   Фото показываются в алфавитном порядке, поэтому удобно называть их `01.jpg`, `02.jpg`…
3. Заполните `index.md` в этой папке:

| Поле | Что это | Обязательно |
|---|---|---|
| `title` | Название галереи под обложкой | да |
| `kategoria` | Категория. Из всех категорий сами появляются кнопки-фильтры | нет |
| `kolejnosc` | Порядок на странице: чем меньше число, тем выше | нет |
| `okladka` | Имя файла-обложки. Можно не указывать, если файл называется `okladka.jpg` или `cover.jpg`; иначе обложкой станет первое фото | нет |
| `opis` | Описание работы | нет |
| `podpisy` | Подписи к отдельным фото: `имя_файла: "подпись"` | нет |

Через 1–2 минуты после коммита сайт обновится сам.
Галерея без фотографий на странице не показывается.

Чтобы удалить галерею, удалите её папку.

## Данные фирмы

Телефон, e-mail, часы работы, NIP и главное фото меняются в файле `_config.yml`.

## Как включить сайт

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**.
3. В пункте **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через пару минут сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Свой домен (например `janicki-wykonczenia.pl`) подключается там же, в **Settings → Pages → Custom domain**.

## Советы по фото

- Уменьшайте фото до ~2000 px по длинной стороне и 300–600 КБ. Фото с телефона весят 4–8 МБ,
  и с ними страница грузится медленно. Подойдёт бесплатный сервис squoosh.app.
- У GitHub есть лимиты: файл до 100 МБ, весь сайт желательно держать до 1 ГБ.
- Ссылкой на конкретную галерею можно поделиться: `адрес-сайта/#имя-папки`.
  При переходе по ней галерея откроется сразу.

## Структура

```
_config.yml          данные фирмы
index.html           страница
assets/style.css     оформление
assets/galeria.js    просмотр фото и фильтры
assets/hero.jpg      главное фото
galerie/<папка>/     галереи: фото + index.md
_wzor-galerii/       образец index.md для новой галереи (на сайт не попадает)
_layouts/            служебные шаблоны
```
